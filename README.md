# 🧩 Sudoku Live Action — Ultra Edition

An ultra-modern, high-aesthetic Sudoku game with dynamic **Live Action** mechanics, synthesized Web Audio SFX, interactive backtracking AI Visual Solver, and responsive glassmorphism UI.

---

## 🌟 Key Features

### 1. ⚡ Live Action Mechanics
- **Combo & Streak Multiplier**: Placing correct digits consecutively increases your combo multiplier up to **5.0x GODLIKE!**
- **Floating Action Popups**: Real-time floating score text (`+100`, `+250 COMBO 2.5x`, `🔥 ON FIRE!`).
- **Live Action Countdown Blitz Mode**: Race against the clock with time bonuses on correct moves (+8s) and time penalties (-10s) on mistakes.
- **Dynamic Particle Engine**: Particle bursts on valid number placement, animated ambient background starfield, and cascading victory confetti shower.

### 2. 🤖 Live AI Visual Auto-Solver
- **Backtracking Visualization**: Watch the AI scan and solve the Sudoku board live in real-time.
- **Color-Coded Analysis**:
  - 🔵 **Electric Cyan**: Cell actively being scanned.
  - 🟢 **Emerald**: Valid candidate accepted.
  - 🔴 **Amber / Red**: Conflict detected & algorithm backtracks.
- **Controls**: Adjustable speed slider (Slow, Medium, Fast, Turbo), Play, Pause, and Single Step.

### 3. 🎨 High-Aesthetic Glassmorphism UI
- **4 Custom Themes**:
  1. **Obsidian Neon** (Cyberpunk deep dark with cyan & purple accents)
  2. **Synthwave Sunset** (Retro 80s dark purple with neon magenta & golden glow)
  3. **Emerald Matrix** (Dark hacker terminal theme)
  4. **Opal Luxury** (Clean, refined sapphire light mode)
- **Visual Aids**:
  - Highlights row, column, and 3x3 region for the active cell.
  - Highlights all matching numbers across the board.
  - Keypad remaining count indicator (shows remaining counts for digits 1–9 and auto-dims when finished).

### 4. 🎵 Synthesized Web Audio Engine
- 100% zero external audio dependencies.
- Musical pentatonic scale pitch corresponding to digits 1 to 9.
- Distinct audio cues for notes, conflicts, combo levels, and victory fanfares.
- Instant mute/unmute toggle.

### 5. 🧠 Logic & Assistance Tools
- **Smart Hint Explainer**: Identifies naked/hidden singles with full explanations.
- **Smart Pencil Notes**: 3x3 mini-grid per cell with automatic pruning when a digit is entered.
- **Undo / Erase Stack**: Full move history.
- **Strikes System**: Optional 3-Mistakes mode or Free Play.
